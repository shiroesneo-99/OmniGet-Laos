        ຟຣີແທ້ບໍ່?

        ຟຣີ ແລະ ເປີດໂຄດທັງໝົດ ພາຍໃຕ້ license GPL-3.0. ບໍ່ມີໂຄສະນາ ແລະ ບໍ່ມີແພັກເກັດເສຍເງິນ.

        ຕ່າງຈາກ OmniGet ສະບັບຕົ້ນແນວໃດ?

        ມີພາສາລາວຄົບທຸກໜ້າ, ຟອນລາວ, ການຖອດສຽງພາສາລາວ ແລະ ການແກ້ໄຂດ້ານຄວາມປອດໄພ. ການອັບເດດຈະມາຈາກ repo ນີ້ ຈຶ່ງຍັງເປັນພາສາລາວຫຼັງອັບເດດ.

        ດາວວິດີໂອຂອງຄົນອື່ນຖືກກົດໝາຍບໍ່?

        ຂຶ້ນກັບເນື້ອຫາ ແລະ ຂໍ້ກຳນົດຂອງແຕ່ລະເວັບ. ໃຫ້ດາວສະເພາະເນື້ອຫາທີ່ທ່ານມີສິດ ເຊັ່ນ ວິດີໂອຂອງຕົນເອງ, ຄອສທີ່ຊື້ແລ້ວ ຫຼື ເນື້ອຫາທີ່ອະນຸຍາດໃຫ້ດາວ. OmniGet ບໍ່ປົດລັອກ DRM.

        ຕ້ອງໃຊ້ browser extension ບໍ່?

        ບໍ່ຈຳເປັນ. Extension ຊ່ວຍດາວເນື້ອຫາທີ່ຕ້ອງລັອກອິນ. ຖ້າຕິດຕັ້ງ, ແນະນຳໃຫ້ໃຊ້ໃນ browser ທີ່ບໍ່ໄດ້ລັອກອິນບັນຊີສຳຄັນ.
